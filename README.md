# Yellow Theli

Next.js 14 (App Router) + TypeScript + Tailwind + Lucide.

    npm install
    npm run dev      # http://localhost:3000
    npm run build && npm start

Edit content in `src/data/` (site.ts, menu.ts, reviews.ts). Replace images in `public/images/`
(hero.jpg, about.jpg, logo.png, menu-*.jpg, icon-*.png) keeping the same file names.
Pixel-exact desktop layout applies from 1536px wide; below that the layout is fluid.
